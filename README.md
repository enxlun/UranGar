# УранГар — демо апп (прототип)

Барилга, засварын **шалгагдсан мастер** дуудаж, ажлын явцад **явуулын машинаас материал** захиалж, **QPay**-ээр төлдөг аппын интерактив прототип. Чацаргана баг.

Компьютер дээр нээхэд утасны хүрээ дотор харагдана. Зүүн талд үзүүлэх дарааллын самбар, баруун талд одоогийн дэлгэцийн тайлбар гарна. Утсан дээр нээвэл бүтэн дэлгэцээр харагдана.

## Ажиллуулах

Node.js 18+ хэрэгтэй.

```bash
npm install
npm run dev          # http://localhost:5173
```

Утсаараа үзэх бол утас, компьютер нэг Wi-Fi-д холбогдсон байхад терминалд гарах `Network:` хаягийг утасныхаа хөтөч дээр нээнэ.

```bash
npm run build        # dist/ — энгийн production build
npm run build:demo   # dist-demo/index.html — бүх зүйл нэг HTML файлд (интернэтгүй нээж болно, фонтоос бусад)
npm run typecheck    # TypeScript шалгалт
```

## Дэлгэцүүд

**Хэрэглэгчийн апп**

1. Splash → угтах дэлгэц → утасны дугаар (iOS тоон гар) → SMS код («Мессежээс: 1234» санал)
2. Нүүр: ангилал, сурталчилгааны карусель, түгээмэл үйлчилгээ (эхлэх үнэтэй), ойролцоох мастер, чацаргана оноо
3. Ажил захиалах: үйлчилгээ сонгох (үнэ, хугацаа), тайлбар, зураг, хурдан / цаг товлох
4. Мастер сонгох: газрын зураг + доод хуудас (ойр / өндөр үнэлгээтэй)
5. Мастерын профайл: үнэлгээ, баталгаажуулалт, сэтгэгдэл
6. Холболт → бодит цагийн хяналт (мастер замдаа, ирсэн, ажил хийгдэж байна)
7. Мастер материал хүсэх → явуулын дэлгүүр (хэмнэлттэй / удаан эдэлгээтэй) → сагс
8. Төлбөр: Замын зардал + Ажлын хөлс + Материал − чацаргана оноо → QPay QR → амжилттай (И-баримт, +1% оноо)
9. Үнэлгээ, захиалгын түүх, профайл, мэдэгдэл, чат

**Мастерын апп** (профайл эсвэл демо самбараас шилжинэ)

1. Онлайн болох → шинэ дуудлага (30 секундийн тоолуур, урьдчилсан орлого 79%)
2. Идэвхтэй ажил: замд гарах → ирэх → үнэ батлах → материал хүсэх → дуусгах
3. Төлбөр орох, орлогын задаргаа (79% / 10% / 10% / 1%)
4. Орлого (7 хоногийн график), профайл, баримт бичиг

## Чацаргана

- Апп-ын тэмдэг нь чацарганы гурван жимс, нэг навч (`components/ui.tsx` → `BerryMark`, `AppIcon`).
- **Чацаргана оноо** — урамшууллын систем: төлбөр бүрийн 1% оноо болж буцна, сэтгэгдэл бичвэл +50, 1 оноо = 1₮.
- Чацарганы зургууд (`src/assets/`) splash, угтах дэлгэц, сурталчилгаа, хоосон төлөв, амжилттай төлбөрийн дэлгэцэнд ашиглагдана.

## Бүтэц

```
src/
  App.tsx              утасны хүрээ, демо самбар, дэлгэц сонгох
  state.tsx            навигаци, захиалга, сагс, мастерын төлөв (React context)
  data.ts              демо өгөгдөл: ангилал, мастер, материал, үнэ, туслах функц
  types.ts             TypeScript төрлүүд
  styles.css           дизайны систем (өнгө, товч, карт…)
  assets/              чацарганы зургууд (WebP)
  components/          MapView, Keypad, QRCode, TabBar, UI жижиг хэсгүүд
  screens/customer/    хэрэглэгчийн дэлгэцүүд
  screens/master/      мастерын дэлгэцүүд
```

## Анхаарах

- Бүх нэр, үнэ, үнэлгээ нь **демо өгөгдөл**.
- Газрын зураг нь загварчилсан зураг. Бодит хувилбарт Google Maps SDK-аар солино.
- QPay QR нь дүрслэл. Бодит хувилбарт QPay API-аар нэхэмжлэх үүсгэнэ.
- Backend байхгүй. Бодит хувилбарт Supabase (auth, database, realtime) холбоно.
